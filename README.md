**🚀 FastAPI Food Delivery Backend**

This project is a backend application built using FastAPI as part of my internship. It simulates a basic food delivery system where users can view menu items and manage orders.

**📌 About the Project**

The application allows users to:

View food menu,
Place new orders,
Update or delete orders,
Search and filter data,
Track order status,
View order summaries and statistics,
It combines all the concepts learned during training into one complete backend system.

**⚙️ Technologies Used**

Python,
FastAPI,
Pydantic,
Uvicorn.
